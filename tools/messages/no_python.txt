
================================================================
  [错误] 这台电脑上没有找到 Python
================================================================

  你运行的是「源码版」，它需要先装 Python 才能用。

  你有两个选择：

  ----------------------------------------------------------
  选择一：装 Python（约 3 分钟）
  ----------------------------------------------------------
    1. 打开 https://www.python.org/downloads/windows/
    2. 下载 "Windows installer (64-bit)" 的最新版
    3. 安装时**务必勾选**最下面那个
           [x] Add python.exe to PATH
       这一步不勾，后面一定找不到 Python。
    4. 装完后重新运行本脚本

  ----------------------------------------------------------
  选择二：改用「免安装版」（推荐，什么都不用装）
  ----------------------------------------------------------
    去拿那个文件名里带「免安装版」的 zip 包，
    解压后直接双击里面的「安卓相册备份.exe」就能用。
    它已经把 Python 和 ADB 全都打包进去了。

  ----------------------------------------------------------
  详细说明见同目录下的「使用说明.txt」第 2 章。
  ----------------------------------------------------------
